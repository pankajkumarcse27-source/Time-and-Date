Time And Date

A simple digital clock made using HTML, CSS and JavaScript.

   Features

* Shows current time
* Shows current day and date
* Updates automatically every second
* Simple and clean UI

     Tech Used

* HTML
* CSS
* JavaScript

   JavaScript Used

* `Date()`
* `getHours()`, `getMinutes()`, `getSeconds()`
* `getDay()`, `getDate()`, `getMonth()`, `getFullYear()`
* `setInterval()`
* Template literals
